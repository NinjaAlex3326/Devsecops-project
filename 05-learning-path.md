# 5. Plan de invatare

1. **Linux & SSH**: ruleaza manual comenzile din `PRESETS` pe un VM.
2. **Terraform**: citeste `terraform/aws/main.tf`, ruleaza `terraform plan` intr-un folder din `data/deployments/`.
3. **Docker**: instaleaza Docker pe VM si ruleaza o aplicatie (adauga un preset).
4. **CI/CD**: adauga GitHub Actions cu Gitleaks, Bandit, Trivy.
5. **Monitorizare**: adauga Prometheus/Grafana sau Uptime Kuma pe un VM.
6. **Freelance**: ofera servicii pachetizate (setup VM securizat, CI/CD, hardening, backup) cu pret fix si documentatie livrata clientului.

## Urmatorii pasi (nu sunt inca in aplicatie)
Provisionare cu Ansible (Docker, firewall, fail2ban), costuri estimate, backup automat, utilizatori multipli, DAST, Terraform remote state.
